# تطبيق محادثة واتساب للموبايل (WhatsApp Mobile Clone) 📱💬

تطبيق محادثة متكامل يحاكي تطبيق **واتساب (WhatsApp)** للهواتف الذكية بأدق تفاصيل التصميم (UI/UX)، الأصوات، والوظائف الفورية (Real-time).

---

## 🌟 الميزات الرئيسية

1. **تصميم مطابق لواتساب (WhatsApp UI/UX)**:
   - واجهة الهاتف الذكي (Mobile Frame) الأنيقة مع شريط الحالة، البطارية، والواي فاي، وإمكانية التكبير لملء الشاشة بنقرة واحدة.
   - خلفية المحادثات الأصلية لواتساب (Doodle Background Pattern).
   - الوضع الليلي الفاخر (WhatsApp Dark Mode) والوضع النهاري (Light Mode).
   - خط عربي عصري وواضح (Cairo Font) مع دعم كامل للاتجاه من اليمين لليسار (RTL).

2. **نظام المحادثات الفوري (Real-time Messaging)**:
   - تبادل فوري للرسائل عبر WebSockets (Socket.IO).
   - علامات الصح المزدوجة الأصلية: صح رمادي (تم الإرسال)، علامتي صح رمادية (تم التسليم)، علامتي صح زرقاء (تمت القراءة).
   - مؤشر الكتابة المباشر ("يكتب الآن...").
   - مؤثرات صوتية أصلية مدمجة عند إرسال واستقبال الرسائل.

3. **الملاحظات الصوتية (Voice Notes)**:
   - تسجيل حقيقي للملاحظات الصوتية بالمايكروفون مع عداد زمني وزر نبض أحمر.
   - تشغيل الرسائل الصوتية داخل المحادثة مع شريط الموجات الصوتية (Waveform).

4. **الوسائط والرموز التعبيرية (Media & Emojis)**:
   - إرسال ومعاينة الصور والملصقات داخل الشات.
   - درج الإيموجي السريع لاختيار الرموز التعبيرية المفضلة.

5. **قسم الحالات والقصص (WhatsApp Status / Stories)**:
   - عارض حالات تفاعلي متقدم مع أشرطة تقدم زمنية علوية (Auto-progressing Story Bar).
   - إمكانية نشر حالة جديدة نصية بخلفيات ملونة متدرجة.

6. **محاكاة المكالمات الصوتية والمرئية (Calls)**:
   - واجهة اتصال كاملة للمكالمات الصوتية والفيديو مع نغمة رنين واتساب الواقعية والرد التلقائي للمحاكاة.
   - أزرار كتم المايك، مكبر الصوت، والكاميرا.

7. **الملف الشخصي والإعدادات (Profile & Settings)**:
   - تعديل الاسم، الأخبار/الحالة (About)، وتغيير الصورة الرمزية.
   - رمز استجابة سريعة (QR Code) خاص بالمستخدم للمشاركة السريعة.

---

## 🚀 طريقة التشغيل السريعة

### الطريقة الأولى (نقرة واحدة على ويندوز):
اضغط نقراً مزدوجاً على الملف:
```cmd
run.bat
```
سيقوم تلقائياً بتشغيل السيرفر والواجهة وفتح المتصفح على `http://localhost:3000`.

---

### الطريقة الثانية (عبر موجه الأوامر Terminal):

1. **تشغيل السيرفر**:
```bash
cd server
node index.js
```
(يعمل على المنفذ `4000`)

2. **تشغيل الواجهة الأمامية**:
```bash
cd client
npm run dev
```
(يعمل على المنفذ `3000`)

افتح المتصفح على: `http://localhost:3000`
